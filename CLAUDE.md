# CLAUDE.md — project instructions for Claude Code

## What this project is
Static marketing + booking website for **DTS — Doctor Therapy Services** (ABA therapy, autism support,
mental-health counseling). Deployed with GitHub Pages from the organization repo
`DrTherapyServices/DrTherapyServices.github.io`; mirrored to `digonto10602/DrTherapyServices-backup`.
Booking backend is a Google Apps Script web app (`backend/Code.gs`) attached to a private Google Sheet.

## Stack — keep it simple
- Plain HTML/CSS/JS. **No build step, no frameworks, no npm dependencies.** GitHub Pages serves the repo root as-is.
- Fonts: Google Fonts (Fraunces + Inter). Everything else is local.
- Illustrations are SVGs generated by `tools/make_illustrations.py` (Python 3, no deps). Edit the script, re-run it, never hand-edit the SVG output.
- Logo files: `assets/logo-mark.svg` (badge), `assets/logo.svg` (horizontal lockup), `assets/logo-mark-light.svg` (for dark backgrounds), `assets/favicon.svg`.

## File map
- `index.html` — home page (hero, trust strip, who-we-help cards, 8 service cards, how it works, CTA, about, FAQ, footer).
- `book.html` + `js/booking.js` — calendar → 30-min slots (9:00–16:30 MT) → details form → confirmation.
- `js/config.js` — the ONLY file that must be edited to go live (`API_URL`, `SITE_KEY`, hours, time zone).
- `js/main.js` — nav, mobile menu, smooth anchor scroll, reveal-on-scroll, progress bar.
- `css/styles.css` — design tokens at the top (`:root`), then components. Palette: green `#2F5D3C`, teal `#3E6B6F`, ochre `#B8622B`, yellow `#E9C46A`, cream `#F4E8CC`, paper `#FBF7EE`, ink `#1C2627`.
- `backend/Code.gs`, `backend/appsscript.json` — Apps Script backend. `SETTINGS` at the top must stay in sync with `js/config.js` (time zone, hours, slot length, SITE_KEY).
- `.github/workflows/mirror-backup.yml` — pushes `main` to the personal backup repo (needs `BACKUP_TOKEN` secret).
- `docs/SETUP_GUIDE.md` — the human step-by-step guide. Update it when behaviour changes.

## Rules
1. Both pages must look right at 390 px (phone) and 1400 px (desktop). Test both after any CSS change.
2. Never break demo mode: with `API_URL: ""` the booking page must still be fully clickable offline.
3. Keep `SITE_KEY` out of commit messages and docs; it's fine in `config.js` (public by design).
4. Do not add analytics, trackers, or third-party scripts without asking.
5. Health-related site: keep crisis footer text (911 / 988), keep the consent checkbox, keep the notes field optional.
6. Copy must not invent credentials, statistics or testimonials. Placeholders are fine if clearly marked `TODO`.
7. Accessibility: keep alt text on illustrations, `aria-*` on calendar/slot buttons, visible focus styles.

## How to run locally
```bash
python3 -m http.server 8000      # then open http://localhost:8000
python3 tools/make_illustrations.py   # regenerate SVGs after editing the script
```
Playwright/Chromium may be used for screenshots: `pip install playwright && playwright install chromium`.

## How to deploy
`git push origin main` → GitHub Pages (about 1 minute). Backend changes: paste `Code.gs` into the Apps Script editor
and **Deploy → Manage deployments → New version** (URL does not change).

## Testing checklist before pushing
- [ ] `index.html` and `book.html` open with no console errors (fonts may fail offline — ignore).
- [ ] Mobile menu opens/closes; anchor links scroll smoothly with nav offset.
- [ ] Calendar: past days, weekends and days beyond `MAX_DAYS_AHEAD` disabled; today marked; month nav limits work.
- [ ] Slots: 16 slots (9:00–16:30); slots less than `MIN_NOTICE_HOURS` away disabled; booked slots greyed.
- [ ] Form: email required + validated, phone optional + validated, consent required, honeypot hidden.
- [ ] Submit → confirmation screen shows date/time in MT and the Meet link.
